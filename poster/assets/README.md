# Tarteel affiliation logo

`tarteel-logo.svg` is the unmodified logo served by Tarteel's public website:
<https://tarteel.ai/logo.svg>, retrieved 2026-10-19.

SHA-256: `6474868d57032e69ed3169adbc1546e28ae2b6f71f881955d02c52f5ee46a743`.

The header uses the site's dark navy (`#020D23`). The logo is used for author
affiliation, not as NVIDIA branding. Tarteel's brand assets are not relicensed
under the repository's Apache-2.0 code license.

The repository QR is generated from its URL by `render.py`; it is not a
downloaded asset. Rendering includes a QR decode check.
